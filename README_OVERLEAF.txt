LEDGER IP&MC 2026 - Overleaf source

1. Upload all files and the sections/ directory in this ZIP to one Overleaf project.
2. Set Main document to: main.tex
3. Set Compiler to: pdfLaTeX
4. Recompile from scratch if bibliography is not shown on the first run.

The manuscript body is split into section files under sections/ and assembled from main.tex with \input.
The paper includes the generated vector architecture figure as fig_architecture.pdf.
fig_architecture_v4.tex is included as the editable TikZ source but is not directly input by main.tex.
